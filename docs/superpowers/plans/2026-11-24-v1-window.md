# herdr-omp-lens v1 Window (P2–P4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. TDD mandatory (superpowers:test-driven-development). Steps use `- [ ]`.

**Goal:** Make the read-only worker window real — observe native subagents (P2), render them in a viewer CLI (P3), and host that viewer in Herdr via the topology manager (P4).

**Architecture:** P2 subscribes `pi.events` `task:subagent:*`, reduces a direct-workers-only roster, and publishes over a per-session unix-socket NDJSON bridge. P3 is an ordinary-pane viewer CLI that connects to the bridge and renders roster + OMP-like transcript (`omp render`). P4 opens/reopens the no-focus overview tab + worker splits and reconciles Herdr lifecycle. The extension activation path owns one HistorySource (P5 stub for now) feeding P2 `opts.history` and P4 `onHistoryPresent`.

**Tech Stack:** Bun, TypeScript strict, Zod (runtime dep), Biome. Builds on P1 (`src/protocol`, `src/herdr`, `src/extension`).

**Spec:** `docs/plans/specs/phase-02-observation-spec.md`, `phase-03-viewer-spec.md`, `phase-04-topology-spec.md`, `00-reconciliation.md` (RC-1..15), SDD §7–10.

## Global Constraints

- Read-only v1: NO `control.*` send; viewer never steers/cancels. Direct workers of the CURRENT session only (direct-id set from `before_subagent_spawn.spawnKey`).
- `SubagentProgress` is an ENVELOPE; counters from nested `.progress`. `WorkerSnapshot` fields per P1 (incl. parentToolCallId/index/modelRole/thinkingLevel/assignment/historical).
- Bridge: per-session socket in a `0700` dir, `0600` socket, unlinked on close/SIGINT/SIGTERM; `ClientMessage` handshake validated; `control.*` rejected; coalesce progress ≤150ms; bounded buffers.
- `LENS_SOCKET_PATH` = `BridgeHandle.socketPath` (NEVER `CallerContext.socketPath`); `LENS_SESSION` = session id; worker splits add `LENS_WORKER_ID`.
- Herdr adapter: `focus:false` always; `env` is a socket-API field; `reportMetadata.source` required; never `agent.start`/`report_agent`/`agent.view.set`/`layout.apply`+`tab_id`.
- Viewer is an ORDINARY pane process: NO Herdr calls itself; thinking visibility = viewer toggle default hidden; transcript via `omp render <sessionFile>` (host-less), NOT `history://` host-less.
- Topology: single-flight state transitions; subscribe-before-create; authoritative reconcile (`getPane`/`snapshot`); `events_lost` resubscribe (P1) + P4 reconcile; reopen on next spawn after close; auto-open on startup when history present (D2).
- Handlers fire-and-forget (never block an OMP turn); no network beyond local unix socket; no `any`/`as any`; Zod boundary validation.
- Gates: `bun test`, `bun run typecheck`, `bun run lint` all green.

## Review Focus

1. Nested/other-session workers leaking into the roster (direct-id filter must exclude them).
2. Bridge socket lifecycle: stale socket reuse, perms, unlink on exit, multi-session collision.
3. Viewer reconnect to a NEW session socket after OMP restart (no dead-socket hang).
4. Topology double-create races (parallel spawns, pane.moved vs tab.closed).
5. A viewer crash or close ever affecting the worker (must never).
